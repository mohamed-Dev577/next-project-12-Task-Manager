📌 نبذة عن المشروع

مدير المهام هو تطبيق ويب يهدف إلى مساعدة المستخدم على تنظيم مهامه اليومية وإدارتها من خلال واجهة مستخدم بسيطة وتفاعلية، تتيح له إضافة المهام ومتابعتها وتحديث حالتها وحذفها عند الحاجة.

✨ المميزات
إضافة المهام: إضافة مهام جديدة إلى قائمة المهام.
عرض المهام: استعراض المهام المسجلة بسهولة.
إكمال المهام: تحديد المهام التي تم إنجازها.
حذف المهام: إزالة المهام التي لم تعد مطلوبة.
التفاعل الفوري: تحديث واجهة المستخدم عند إجراء تغييرات على المهام.
🛠️ التقنيات المستخدمة
التقنية	الاستخدام
Next.js	إطار عمل لتطوير تطبيقات الويب
React	بناء واجهة المستخدم التفاعلية
JavaScript	تنفيذ منطق التطبيق
CSS	تنسيق واجهة المستخدم
🎯 أهداف المشروع

يهدف المشروع إلى تطوير المهارات العملية في بناء تطبيقات الويب، مع التركيز على:

إدارة الحالة باستخدام useState.
التعامل مع أحداث المستخدم.
عرض القوائم الديناميكية باستخدام map().
تحديث واجهة المستخدم بناءً على تغييرات الحالة.
تنظيم مكونات React وبناء واجهات تفاعلية.
👨‍💻 عن المطور

هذا المشروع جزء من سلسلة مشاريع عملية تهدف إلى تطوير المهارات في مجال تطوير واجهات المستخدم (Front-End Development)، والتدرب على بناء تطبيقات ويب باستخدام React وNext.js.
